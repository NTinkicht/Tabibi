# Tabibi

Tabibi is an Algeria-first doctor appointment and intelligent queue-management platform.

The product combines appointment booking, hybrid walk-in/reception queues, live queue position, estimated consultation time, and proactive notifications so patients do not need to spend hours physically waiting in clinics.

This repository also serves as the shared engineering workspace for a multi-model development process:
- ChatGPT/Codex: lead engineering, implementation, tests, CI, architecture maintenance
- Claude: independent architecture, security, correctness, privacy, and QA review
- GitHub: source of truth and communication bus
- Nassim: product owner and final escalation authority
