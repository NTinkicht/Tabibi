## Evidence status vocabulary

- **IMPLEMENTED — TEST LOCATED:** an implementation and meaningful repository test can be pointed to. Their presence does not by itself prove current-main execution.
- **RELEASE-SYNTHETIC:** the committed release matrix documents a passing bounded, synthetic clinic-day acceptance; verify on the exact release candidate and do not extrapolate to actual patient/provider deployment.
- **AUDIT REQUIRED:** the original acceptance criterion is wider than the immediately identified code/tests or needs dedicated negative/concurrency verification.
- **NOT VERIFIED IN PRODUCTION:** no real clinic/patient/provider evidence is asserted.
